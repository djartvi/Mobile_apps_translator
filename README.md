# Mobile apps translator

Переводит строки iOS (`Localizable.strings`) и Android (`strings.xml`) на нужные языки через Google Translate. Ещё умеет искать и заменять текст в файлах, сравнивать два файла, подставлять сокращения дней недели и конвертировать iOS ↔ Android.

## Запуск

1. Положить исходный файл в `to_do/`.
2. В `src/main/java/main/Settings.java` указать платформу, исходный язык и языки перевода.
3. В `Main.java` оставить раскомментированной нужную задачу и запустить `main.Main` из IDE.

Результат — в `translate_result/<язык>.lproj/` или `translate_result/values-<язык>/`. Повторный запуск переводит только ключи, которых там ещё нет, ручные правки не затирает. Если текст строки поменялся при том же ключе, перевод не обновится — удалите папку языка. Строки, где плейсхолдеры (`%@`, `%d`, `\n`…) разошлись с оригиналом, выводятся в консоль.

## Структура

- `Main` — список задач
- `Settings` — настройки
- `Translator` — перевод через Google
- `StringsFile` — чтение и запись `.strings` и `strings.xml`, конвертер
- `DaysOfWeek` — словарь и подстановка дней недели
- `FileTools` — поиск, замена, сравнение
